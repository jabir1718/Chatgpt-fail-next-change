# Viso Studio Roadmap

M0 clean Android foundation and verified APK.
M1 editor timeline and media import.
M2 independent audio clip controls.
M3 beat-reactive visualizer with background and foreground image layers.
M4 automatic multilingual captions and voice input.
M5 cutout, chroma key, effects and compositing.
M6 platform export and supported social sharing.

A milestone is complete only after CI build and acceptance tests. A visual mockup is not proof that a media engine works.
